# CAR VAULT — Luxury Automotive Dealership Web Platform

**CAR VAULT** is a luxury automotive showcase and dealership web platform crafted with a sleek black-and-gold aesthetic. It allows users to explore exotic vehicles, compare specifications, schedule private test drives, and connect with showroom specialists.

---

## Key Features & Pages

- **Consistent Luxury Design (`style.css`):** Unified dark-mode theme with metallic gold accents, responsive typography, a 12-link horizontal navigation header, and a 3-column structured footer across all pages.
- **About Us (`about.html`):** Highlights the CAR VAULT brand story, core values, heritage, and showroom philosophy.
- **Contact & Concierge (`contact.html`):** Displays Islamabad showroom contact details, business hours, and an interactive customer inquiry form.
- **Help & FAQ (`faq.html`):** Features an interactive accordion-style Q&A section answering common questions about vehicle bookings, test drives, financing, and showroom visits.
